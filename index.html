📱 Installer Leo AI

      
    

    

      Installez Leo AI comme une vraie application sur votre ecran d'accueil. Fonctionne sans connexion, aucune boutique d'applications.
    


    
    

      
 iPhone / iPad (Safari)

      

        
1️⃣ Ouvrez ce fichier dans Safari

        
2️⃣ Appuyez sur le bouton Partager ⬆️

        
3️⃣ Faites defiler vers le bas

        
4️⃣ Appuyez sur «Sur l'ecran d'accueil»

        
5️⃣ Appuyez sur Ajouter ✓

      

    


    
    

      
🌐 Android (Chrome)

      

        
1️⃣ Ouvrez ce fichier dans Chrome

        
2️⃣ Menu ⋮ en haut a droite

        
3️⃣ Appuyez sur «Ajouter a l'ecran d'accueil»

        
→ Ou attendez la banniere automatique Chrome

      

    


    
    

      
⚡ Mode hors-ligne complet (optionnel)

      

        Pour un fonctionnement entierement hors-ligne, deposez le fichier HTML + sw.js sur un hebergeur HTTPS gratuit comme GitHub Pages ou Netlify, puis ouvrez l'URL depuis votre mobile.
