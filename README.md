# CR de terrain — CSPS17

Comptes rendus de chantier sur tablette Android, hors réseau, sans serveur ni IA.
Les données restent dans la tablette (IndexedDB). Rien n'est envoyé ailleurs.

- `index.html` : l'application complète (bibliothèques Word et modèle intégrés).
- `sw.js` : fonctionnement hors réseau. Changer `VERSION` à chaque mise à jour.
- `source/` : sources (page, génération du Word, modèle du CR de visite v3).

Étape 1 livrée le 28/09/2026 : CR de visite de chantier.
